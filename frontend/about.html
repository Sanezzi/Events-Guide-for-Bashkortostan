О сервисе

Единый достоверный доступ к афише культурных мероприятий Республики Башкортостан: концерты, спектакли, выставки, фестивали, кинопоказы и экскурсии. Сервис готов к встраиванию в официальный сайт Министерства культуры через открытый API и виджет — без изменения действующих систем министерства.

Нельзя выдумывать

Каждое утверждение в ответе опирается на запись в базе и её источник. Пустая выдача — нормальный, честный результат.

Нельзя зависеть от одного сервиса

При недоступности модели каталог, поиск и карточки продолжают работать, а чат переходит в резервный режим.

Короткий путь

Не более трёх действий до карточки события: фильтры или свободный запрос → подборка → карточка и источник.

Как работает агент

Агент — не «чат с моделью поверх базы», а исполнитель с формальным контрактом: вход — текст и последние реплики диалога, выход — текст, карточки с идентификаторами и, при неоднозначности, один уточняющий вопрос. Не более пяти вызовов инструментов на ответ: поиск по фильтрам, карточка события, похожие события, расписание площадки, подписка, обращение организатору. Каждый факт берётся только из результата инструмента.

Действия, меняющие данные (подписка, обращение), выполняются только после явного подтверждения: предложение привязано к версии, действует 300 секунд и отключается после клика или нового запроса.

API и встраивание

Версионированный REST API: список событий с фильтрами, пагинацией и сортировкой, карточка события, похожие события, справочники городов, площадок и категорий, подписки и обратная связь. Единый формат ошибок: код, сообщение, детали.

Данные этой демонстрации

Каталог наполнен подготовленным демо-набором из примеров проекта (Стерлитамак, 5 января 2030 года): события помечены как ДЕМО и являются синтетическими, а не реальной афишей. Механизм — каталог, фильтры, дедупликация при загрузке, статусы, подписки, агент — работает по-настоящему; реальный набор Контура подключается заменой репозитория без изменения API и фронта.
