# Афиша культуры Башкортостана

Веб-афиша и Telegram-бот для поиска культурных событий, планирования посещений и подписок. Веб-приложение и бот работают с одним каталогом событий через FastAPI.

## Быстрый запуск

1. Установите Docker с плагином Compose и запустите Docker. На Windows и macOS подойдёт Docker Desktop.
2. Скачайте ZIP через **Code → Download ZIP** и распакуйте его или клонируйте репозиторий.

   ```sh
   git clone https://github.com/Sanezzi/Events-Guide-for-Bashkortostan.git afisha
   cd afisha
   ```

3. В корне проекта скопируйте `.env.example` в `.env`. Команда PowerShell - `Copy-Item .env.example .env`. В Bash - `cp .env.example .env`.
4. Откройте `.env` и задайте свой пароль в `POSTGRES_PASSWORD`. Для доступа к модерации задайте отдельное случайное значение в `ADMIN_TOKEN`.
5. Соберите и запустите приложение.

   ```sh
   docker compose up -d --build
   docker compose ps
   ```

| Адрес | Назначение |
| --- | --- |
| <http://localhost:8000/> | Каталог событий и ИИ-гид |
| <http://localhost:8000/planner> | Планировщик |
| <http://localhost:8000/subscribe> | Подписки на события |
| <http://localhost:8000/organizers> | Предложить событие |
| <http://localhost:8000/admin> | Модерация и импорт. Для входа используйте свой `ADMIN_TOKEN` |
| <http://localhost:8000/widget> | Встраиваемый каталог |
| <http://localhost:8000/docs> | Swagger UI с описанием REST API |
| <http://localhost:8000/health> | Проверка соединения с базой и количество опубликованных карточек |

Для диагностики используйте `docker compose logs -f api`. Команда `docker compose down` остановит приложение. Данные сохраняются в томе `pgdata`.

## Настройка

Все значения заполняются в локальном файле `.env`. Git игнорирует этот файл.

| Переменная | Значение |
| --- | --- |
| `POSTGRES_PASSWORD` | Ваш пароль для базы PostgreSQL в Docker Compose |
| `HOST_PORT` | Порт сайта в Docker, по умолчанию `8000` |
| `ADMIN_TOKEN` | Ваш токен для входа в модерацию и заголовка `X-Admin-Token` в API |
| `BOT_TOKEN` | Токен нового бота, полученный через [BotFather](https://t.me/BotFather) |
| `INTERNAL_API_TOKEN` | Отдельная случайная строка для доступа бота к API. Compose передаёт её обоим сервисам |
| `ADMIN_IDS` | JSON-массив числовых Telegram ID администраторов бота. Пустой список - `[]` |
| `WEBAPP_URL` | HTTPS-адрес вашего сайта для кнопки в боте |
| `LLM_API_KEY` | Ключ вашего провайдера LLM. При пустом значении ИИ-гид ищет по локальному каталогу |
| `LLM_BASE_URL`, `LLM_MODEL` | URL совместимого с OpenAI API и идентификатор модели |
| `SEED_CONFIRMED_EVENTS` | `1` загружает стартовый снимок афиши при первом запуске, `0` пропускает загрузку |
| `PUBLIC_BASE_URL` | HTTPS-адрес сайта для канонических ссылок, карты сайта и RSS при развёртывании за прокси |
| `SESSION_SECRET` | Ключ подписи веб-сессий. При пустом значении он создаётся в базе автоматически |

Для запуска Telegram заполните `BOT_TOKEN` и `INTERNAL_API_TOKEN`, затем включите профиль `telegram` и отправьте своему боту `/start`.

```sh
docker compose --profile telegram up -d --build
docker compose logs -f bot
```

Остановить сайт и бота можно командой `docker compose --profile telegram down`.

ИИ-гид принимает, например, запрос «Найди спектакль в Уфе на выходных до 1500 рублей». Для подключения LLM заполните её параметры и перечитайте их командой `docker compose up -d api`. Запросы чата в этом режиме отправляются настроенному провайдеру.

## Как загрузить свои события

- Откройте **Модерация → Импорт CSV или JSON** и загрузите файл. В [примере](examples/events.json) показана структура JSON. Для CSV используйте те же поля как заголовки столбцов, кодировку UTF-8 и часы с часовым поясом, например `2030-06-01T13:00:00+05:00`.
- Замените значения примера данными своего события. Для проверки отправьте запись со статусом `черновик`, затем переведите её в `опубликовано` в панели модерации.
- Чтобы начать с пустого каталога, установите `SEED_CONFIRMED_EVENTS=0` до первого запуска. Стартовые карточки отражают даты снимка. Актуальные события можно импортировать в любое время.
- Сборщик читает структурированную разметку событий на страницах организаторов и добавляет карточки в очередь модерации. Передайте адрес своей афиши или используйте список в [contour/data/sources.json](contour/data/sources.json).

```sh
docker compose exec api python -m contour.collect --preview "https://example.org/events"
docker compose exec api python -m contour.collect "https://example.org/events"
```

Замените `https://example.org/events` адресом настоящей афиши. Флаг `--preview` показывает, что сборщик смог извлечь. Для обработки всех адресов из файла используйте `--configured`.

## Как связаны модули

| Откуда | Куда | Что передаётся |
| --- | --- | --- |
| Браузер · `src/`, `frontend/` | FastAPI · `app/` | Запросы каталога, подписки, предложения событий и сообщения чата |
| Telegram | `tg_bot/` | Команды пользователей и нажатия кнопок. Бот отвечает сообщениями и карточками |
| `tg_bot/` | FastAPI · `/internal/bot/`, `/agent/message` | Поиск, карточки, подписки, уведомления и сообщения ИИ-гиду через сервисный токен |
| Страницы организаторов | `contour/collect.py` и `contour/parser.py` | Структурированная разметка событий |
| Сборщик или панель модерации | `app/catalog.py` → `tg_bot/services/importer.py` → база данных | Проверенные на соответствие схеме карточки. Сборщик создаёт черновики |
| FastAPI · `/api/chat`, `/agent/message` | `ai_agent/` | Текст, контекст диалога и подтверждения действий |
| `ai_agent/` | Каталог и опциональный LLM API | Ограничения для поиска в каталоге, вызовы инструментов и подборки по реальным карточкам |
| `app/` и `migrations/` | PostgreSQL в Compose или локальная SQLite | Каталог, подписки, обращения и служебные записи |

## Запуск без Docker

Установите Python 3.13 и Node.js 22. Создайте `.env` из шаблона и оставьте `POSTGRES_PASSWORD` пустым для SQLite. При необходимости задайте `ADMIN_TOKEN`.

**Windows PowerShell**

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
npm.cmd ci
npm.cmd run build
.\.venv\Scripts\python.exe -m uvicorn app.main:app --env-file .env --host 127.0.0.1 --port 8000
```

**Linux и macOS**

```sh
python3.13 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
npm ci
npm run build
.venv/bin/python -m uvicorn app.main:app --env-file .env --host 127.0.0.1 --port 8000
```

Откройте <http://localhost:8000/>. Локальная база создаётся в `afisha.db`. Для бота в этом режиме добавьте `BACKEND_URL=http://127.0.0.1:8000` в `.env` и в соседнем терминале запустите `python -m tg_bot.main` из того же виртуального окружения.

Для тестов установите `requirements-dev.txt` в виртуальном окружении и выполните `python -m pytest -q`. Сценарии ИИ-агента запускаются командой `python -m ai_agent.test_eval --adversarial`.
